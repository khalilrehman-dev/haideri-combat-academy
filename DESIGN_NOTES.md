# Design notes

## Identity retained

The original website's charcoal, white and red palette is retained. The main tokens remain background `#070a0d`, soft background `#0c1116`, panels `#10161c` / `#141c24`, text `#f6f7f8`, muted text `#9aa5af` and accent `#ef2437`. Primary button fills use a slightly darker red (`#d91f32`) for white-label contrast. WhatsApp has its distinct green action treatment.

The supplied gold/silver lion-shield logo has not been regenerated, restyled or recolored. Its exact original file is included. Icons use a crop of the same artwork, not a different lion. Coach imagery is derived from the supplied photograph, not an AI reconstruction. The team image comes from the original uploaded website.

## Public design references reviewed

- Evolve MMA: https://evolve-mma.com/ - discipline-led browsing, clear training paths and prominent enquiries.
- Renzo Gracie Academy: https://renzogracieacademy.com/ - clear academy/program/coach information hierarchy.
- Evolve MMA instructors: https://evolve-mma.com/instructors/ - category-based discovery.

These informed navigation and information structure. Their logos, photography, copy and page layouts have not been copied into this website.

## Specific decisions

An editorial homepage balances a large headline with the real coach photo. Shared spacing, thin borders, clear typography, restrained red accents and consistent buttons connect all pages. The mobile drawer includes labeled icons and direct routes to the stance guide and topics. Desktop and mobile use the same content, not a reduced placeholder mobile site.

Photos and videos are separate collections with independent search and filters. Individual topic pages connect related media and training information. The stance explorer is a simple orientation reference, not a substitute for supervised instruction. No invented prices, class timetable, championship record, reviews or location text have been added.

WhatsApp is a link to the user's supplied academy number, not an automatic sender. Contact-form messages still need to be sent by the visitor inside WhatsApp.
